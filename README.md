# STM32 多功能菜单系统

基于STM32的多功能外设控制项目，通过OLED屏幕显示菜单，使用三个按键进行交互。支持蜂鸣器播放摩斯码、DHT11温湿度读取、LED控制、质数计数器以及摩斯码数字输入识别。

## 硬件需求
- STM32微控制器
- OLED显示屏（I2C接口）
- 三个按键（KEY1, KEY2, KEY3）
- 蜂鸣器
- LED（LED2）
- DHT11温湿度传感器

## 功能说明

### 1. 菜单导航
- **KEY1**：向上选择菜单/子菜单切换
- **KEY2**：向下选择菜单/子菜单切换
- **KEY3**：进入子菜单/返回主菜单

菜单项：
- **HOME**：显示“HI”
- **BUZZER**：蜂鸣器摩斯码功能
- **TEMP**：显示DHT11温湿度
- **LED**：LED开关控制
- **COUNT**：质数计数器

### 2. BUZZER子菜单
- **K1: HELLO**：播放“HELLO”的摩斯码音频，播放完成后自动返回
- **K2: NUM**：进入摩斯码数字输入模式

### 3. 摩斯码数字输入
- 进入后显示 `NUM:?`
- **K1**：输入点 `.`
- **K2**：输入划 `-`
- 输入满5个符号后自动识别数字（0-9），蜂鸣提示并显示结果
- 再次按下K1或K2重置并开始新输入
- **K3**：退出输入模式

### 4. TEMP子菜单
- 显示当前温度和湿度，带单位`°C`和`%`

### 5. LED子菜单
- 显示LED状态（ON/OFF）
- **K1/K2**：切换LED状态和蜂鸣器联动

### 6. COUNT子菜单
- 显示质数计数器数值
- **K1**：跳到下一个质数
- **K2**：计数器清零

### 7. 开机画面
- 上电显示标题停留3秒后进入菜单
